# Platen 0.3.0-alpha.1

Status: release candidate, not published.

Platen `0.3.0-alpha.1` is the first structured public-alpha candidate for
the local browser GUI, CLI, loopback host, capability catalog, and optional
native helpers in this source tree.

## Included behavior

- Local PDF viewing, inspection, search, page navigation, and original-file
  download.
- Bounded page arrangement, OCR, conversion, export, comparison,
  accessibility-review, prepress-review, and source-bound mutation subsets.
- Immutable private source storage and separately validated derived artifacts.
- Strict no-clobber CLI output publication.
- Machine-readable distinction between professional delivery and narrower
  prototype coverage.

## Known limitations

- Interfaces and output contracts may change during the alpha period.
- Third-party plugin installation and execution are disabled.
- AI functions are catalog-only and excluded from implementation.
- Many professional functions remain planned or constrained to a subset,
  sidecar, descriptor, or local service.
- Optional engine availability varies by system.
- Browser-native PDF behavior and optional PDFKit behavior vary by platform.
- Accessibility and prepress review do not establish standards conformance.
- Signature inspection does not establish signer identity, revocation, legal
  effect, or trust on another system.
- CLI output paths require an access-controlled directory until descriptor-bound
  publication is verified against concurrent path substitution.
- Local release validation does not establish distribution trust.

## Upgrade and migration

There is no supported migration from an earlier published release. Local
automation journals, project bundles, plugin state, and derived artifacts are
alpha formats and must not be assumed compatible with later releases. Keep the
original PDF and export any evidence required outside the application before
upgrading.

## Verification

The candidate must pass the commands in `docs/RELEASING.md` from the exact Git
commit proposed for release. The current local evidence is recorded in
`RELEASE_STATUS.md`.
